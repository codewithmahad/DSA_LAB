# Problem note template

Copy this file as `README.md` beside a problem’s `Main.java`, or use the [folder helper](../scripts/). Replace this introduction and heading with the problem title. Keep the original statement at its source; write my own short notes here.

**Source:** Add the original problem URL and its platform ID, if any.

**State:** Planned

**Help used:** Not recorded.

**Submission:** Not submitted / not recorded. Add the result and a submission link if available after submitting.

## Approach

What did I try? Why should it work? Include the invariant or the choice that makes the approach valid. Keep a failed approach if it explains a useful mistake.

## Cost & checks

- **Time:** Not analysed yet. Define what `n` represents.
- **Extra space:** Not analysed yet. Include recursion space and distinguish output space.
- **Checks:** Not run yet. Record inputs, expected results, and observed results; include a boundary or a case that broke the first attempt.

## Revisit

Add a date after returning in a later session. What could I rebuild before looking at the old code, and what still needed help?
