# 13 · Dynamic programming

## Coverage

- Start from a recursive formulation and identify repeated subproblems.
- Define state, transitions, base cases, and evaluation order.
- Compare memoization and tabulation.
- Practise one-dimensional, grid, subset/knapsack, and sequence/string families.
- Study longest increasing subsequence and interval DP after the basic families.
- Reduce space only after understanding dependencies, and reconstruct an answer when required.

## Java notes

Choose safe sentinels and avoid adding to an unreachable value. Track whether an in-place update reads the current or previous row.
