# 09 · Trees & BSTs

## Coverage

- Implement preorder, inorder, postorder, and level-order traversals.
- Compare recursive DFS, iterative DFS, and BFS.
- Compute height, balance, diameter, and path properties.
- Use BST ordering for search, insertion, validation, and kth-element questions.
- Find lowest common ancestors and reconstruct or serialize small trees.

## Java notes

Use an explicit node class and handle null children. Reset per-run state so repeated checks do not influence each other.
