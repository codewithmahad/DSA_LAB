# 10 · Heaps & priority queues

## Coverage

- Trace a binary heap, sift-up, sift-down, and heap construction.
- Use a min-heap and a max-heap with a comparator.
- Keep the best k items and compare heap work with full sorting.
- Merge sorted streams or lists.
- Apply priority queues to scheduling and, later, graph shortest paths.

## Java notes

Read PriorityQueue’s ordering and iteration contracts. Include a tie-breaker when the problem needs deterministic ordering.
