# 12 · Graphs

## Coverage

- Build adjacency lists for directed/undirected and weighted/unweighted graphs.
- Use BFS/DFS for components, reachability, and grid problems.
- Detect cycles and test bipartite graphs.
- Find a topological order with indegrees or DFS and detect when none exists.
- Use BFS for unweighted shortest paths and Dijkstra for nonnegative weights.
- Use disjoint-set union with path compression and union by size/rank; study minimum spanning trees.

## Java notes

Use ArrayDeque for BFS and long for accumulated distances when needed. Test disconnected vertices, cycles, and repeated edges where allowed.
