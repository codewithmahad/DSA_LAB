# 14 · Bits & maths

## Coverage

- Set, clear, toggle, and test bits; distinguish signed and unsigned shifts.
- Use XOR identities, bit counts, and power-of-two checks.
- Compute GCD/LCM and reason about overflow.
- Check primality and build a sieve.
- Use modular arithmetic and binary exponentiation.
- Represent small subsets with bitmasks after the basic operations are clear.

## Java notes

Check int versus long shifts and arithmetic before applying a modulus. Practise with zero, one, and upper-bound inputs.
