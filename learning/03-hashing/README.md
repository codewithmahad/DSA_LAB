# 03 · Hashing

## Coverage

- Use sets for membership and maps for counts or remembered positions.
- Solve duplicate, pair-sum, anagram, and grouping patterns.
- Combine prefix sums with a map for subarray questions.
- Explain hashing, collisions, load factor, and expected versus worst-case lookup costs.
- Reason about key equality, mutable keys, missing entries, and iteration order.

## Java notes

Practise getOrDefault, merge, and computeIfAbsent when they make intent clearer. Check equals and hashCode for custom keys.
