# 04 · Searching & sorting

## Coverage

- Implement linear search and iterative binary search.
- Find first/last matches and insertion boundaries; choose a consistent interval convention.
- Search rotated inputs and monotonic answer spaces.
- Implement insertion sort, merge sort, and quicksort; compare time, space, and stability.
- Use library sorting and custom comparators, including tie-breaking.

## Java notes

Compare numbers with Integer.compare or Long.compare rather than subtraction. Check whether sorting changes the original input.
