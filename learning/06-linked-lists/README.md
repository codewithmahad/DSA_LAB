# 06 · Linked lists

## Coverage

- Build and traverse a simple singly linked list.
- Insert and delete using a dummy node where it simplifies boundaries.
- Reverse a list iteratively and trace the reference changes.
- Find a midpoint and detect a cycle with fast/slow pointers.
- Merge sorted lists and locate relative positions such as the kth node from the end.

## Java notes

Keep node identity separate from value equality. Save the next reference before changing a link.
