# 07 · Stacks & queues

## Coverage

- Implement small stack and queue experiments and explain their operation costs.
- Use ArrayDeque for stack and queue patterns.
- Match brackets and trace expression or undo-style state.
- Use a monotonic stack for next-greater and next-smaller questions.
- Use a monotonic deque for window extrema after the basic patterns are comfortable.

## Java notes

Practise push/pop/peek separately from offer/poll/peek. Read ArrayDeque’s null and empty-operation contracts.
