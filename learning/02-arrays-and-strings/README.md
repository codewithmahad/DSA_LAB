# 02 · Arrays & strings

## Coverage

- Traverse, update, reverse, rotate, and compact arrays in place.
- Work with subarrays, subsequences, prefix sums, and maximum-subarray reasoning.
- Handle basic string traversal, character counts, palindromes, and StringBuilder.
- Traverse matrices and reason about row and column boundaries.
- Check empty, single-element, repeated, negative, and already ordered inputs where allowed.

## Java notes

Decide whether modifying the input is allowed. Distinguish char positions from Unicode code points when a problem requires it.
