Keep concept experiments in `learning/` and problem attempts in `problems/` within the relevant topic. Create those subfolders when adding actual work. Keep one copy of a solution, even if several sheets include it.

The checklists start unchecked. Update them when there is code or reasoning I can return to, then link that work in the [weekend log](../progress/README.md).
