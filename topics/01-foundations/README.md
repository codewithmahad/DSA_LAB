# 01 · Foundations

Build the habits I’ll use in every problem: trace the code, state what stays true, and account for the work it does.

## Planned coverage

- [ ] Analyse constant, logarithmic, linear, n log n, and quadratic growth with small dry runs.
- [ ] Distinguish worst-case, average-case, and amortized costs; count extra memory and recursion space.
- [ ] State a loop invariant and check initialization, maintenance, and termination.
- [ ] Choose among arrays, ArrayList, HashMap, HashSet, ArrayDeque, and PriorityQueue.
- [ ] Check integer overflow, casting, equality, and input constraints before choosing types.

## Checkpoint

Explain the time and extra space of a traversal, a nested loop, and a halving loop, then verify the reasoning with small inputs.
